Abstract
Phishing is a cyber-attack in which the attacker redirects Internet users to fraudulent websites. Fake websites look very similarto legitimate ones, leading users to trust them and disclose sensitive information. Despite the available methods, these attacks
have grown exponentially, emphasizing the need for advanced techniques. This study proposes an EGSO-CNN model to
detect web phishing by integrating features and optimizing deep learning (DL) techniques. A novel dataset has been createdto address the availability of existing updated phishing datasets. The StandardScaler and Variational Autoencoders (V AE) are
employed for preprocessing and feature extraction. The Enhanced Grid Search Optimization (EGSO) technique optimizes
the model’s performance. The proposed model yields an accuracy of 99.44%, a recall of 99.21%, and an f1-score of 99.32%with low false positive and error rates. The presented model can assist management by selecting effective phishing detection
strategies to enhance customer delight.
Keywords Phishing attacks ·Deep learning ·Optimization techniques ·User awareness

2 Background and related work
This section discusses the study background, existing
datasets, and ML and DL-based studies on web phishing
detection.
2.1 Background of the study
The phishing phenomenon was initially documented in 1996
in the hacker newsgroup [ 16]. The term "phishing" origi-
nated from the word "ﬁshing," with the substitution of the
letter "f" with "ph" [ 17]. A user account with compromised
credentials is generally called phishing, and the person whosuccessfully obtains the stolen credentials is known as thephisher. A phishing website is designed to emulate a real
website and steal users’ sensitive information to exploit it
[18]. Attackers commonly manipulate a target webpage’s
hostname and path components to create a phishing UR
[19]. The term URL (Uniform Resource Locator) refers to
a web address that identiﬁes the location of a resource. Aweb resource can encompass various formats, including web
pages, text ﬁles, emails, images, and database access [ 20]. A
URL consists of two primary elements: the protocol identi-ﬁer and the resource path. Figure 3shows the phishing lifecycle. First, an attacker creates a phishing website similar to a
legitimate website. The attackers manipulate URL elements,
such as the domain name and network resource directory,
by introducing spelling errors or using similar alphabeticcharacters to create a clone version of a legitimate website.
For example, the URL " https://aimazon.az-z7acyu3z0y10.
abc/m " replicates the appearance and functionality of the
legitimate website " https://www.amazon.com ." When users
access fake websites, attackers capture sensitive information
for exploitation.
2.2 Existing dataset
The quality of the dataset plays a crucial role in the per-
formance of the detection model. We review the publicly
available web phishing datasets, which are the most popu-
lar, widely used, and comprehensive. Several web phishingdetection studies often use the PhishTank [ 21] dataset. This
dataset encompasses approximately seven million records
related to phishing URLs and is developed as a benchmark
for ML and DL-based web phishing detection systems. Alexa[22] is an online platform developed by Amazon that offers a
range of analytical tools for evaluating website performance.
Its ranking system utilizes probability to rank millions ofbenign website URLs. The OpenPhish [ 23] dataset contains
URLs associated with phishing activities and provides meta-
data, including page content and IP address. The Kaggle[24] offers a web phishing detection dataset containing 87
extracted features.
The Mendeley [ 25] published in 2021, this dataset consists
of authentic and phishing website samples. Each instancecontains the URL and the corresponding HTML page. The
PhishStorm [ 26] is a publicly available phishing dataset
consisting of a CSV ﬁle. The domain column provides aunique identiﬁer for each entry. The label column provides
the domain entry status: 1 for legitimate and 1 for phish-
ing. Table 1summarizes the publicly available web phishing
datasets.

2.3 ML-based phishing detection
Machine learning usage has signiﬁcantly increased in various
domains over the last decades. Ahammad et al. [ 27] presented
a study on web phishing detection using ﬁve ML classiﬁers.
The study employed the Phish Tank dataset of 3000 URLs.
The LightGBM classiﬁer achieved an accuracy of 89.5%, butthe study considered the limited features. Alani et al. [ 28]
offered a comprehensive analysis of phishing URL detection
employing ML techniques. In the feature selection stage, thelimited necessary features are eliminated through recursivefeature elimination. The dataset was created by collecting
data from Phish Tank and Alexa datasets. The random forest
classiﬁer demonstrated the highest accuracy of 97.5% but,the proposed model was evaluated in the cloud environment.
Korkmaz et al. [ 29] presented a study on web phishing detec-
tion ML-based techniques using eight different classiﬁers.The authors utilized different evaluation metrics, i.e., accu-
racy, TPR, FPR, TNR, FNR, precision, f1-score, and time.
Barraclough et al. [ 30] proposed a study on intelligent online
cyber phishing attack detection, integrated web content, andheuristic-based approaches using different techniques. The
authors demonstrated an accuracy of 99.33% using the PART
classiﬁer.
Jain et al. [ 31] presented an effective approach to detect-
ing web phishing pages using ML classiﬁers. The author
employed effective feature selection techniques to detectzero-day attacks and used the Alexa dataset. The proposed
model was evaluated using ﬁve different ML classiﬁers, and
the random forest classiﬁer achieved the highest accuracyof 93.85%. Sánchez-Paniagua et al. [ 32] proposed a model
based on ML techniques for phishing detection and utilized
handcrafted feature selection. Three sets are employed: legit-
imate home, login, and phishing. The authors validated themodel using eight ML classiﬁers. The LightGBM yielded
the highest accuracy of 94.67% using PIU-60 k datasets,
and XGBoost accomplished an accuracy of 93.22%. Jhaet al. [ 33] proposed a study identifying and distinguish-
ing a web phishing website. Using logistic regression, the
authors exhibited the highest accuracy of 98% comparedto the ML classiﬁers employed. Karim et al. [ 34] studiedphishing URL detection using hybrid ML techniques. The
study used voting techniques that combined multiple ML
classiﬁers, and a canopy-based feature selection technique
was utilized. The author achieved an accuracy of 98.12%,a precision of 97.31%, and an f1-score of 95.89%. Shirazi
et al. [ 35] presented a study on phishing detection based
on synthetic data generation using adversarial autoencoderand WGAN-based (Wasserstein Generative Adversarial Net-
work) techniques. The authors achieved an accuracy between
97 and 98% in detecting phishing URLs using different ML-based classiﬁers. The study considered limited features anddid not consider the data-cleaning process. Pandey et al. [ 36]
proposed a model for web phishing detection based on the
web page’s predominant color. The authors employed ﬁveML classiﬁers, and the random forest classiﬁer demonstrated
the highest accuracy of 99.13%. The study considered a lim-
ited number of features and did not consider the error rate.

3.1 Data collection
The signiﬁcant challenge in web phishing attack detectionis the availability of the dataset. Benchmark datasets allow
researchers to effectively compare the performance of their
models. However, data quality plays a critical role in deter-mining a model’s accuracy and reliability. A major issue is
the absence of a comprehensive and up-to-date labeled train-
ing dataset, which hampers the development of effective MLand DL-based web phishing detection systems. The contin-
uous evolution of phishing URLs and inclusion of expired or
outdated samples in existing datasets can negatively affecta model’s accuracy [ 47]. Biased detection can result from
unequal distributions of phishing versus legitimate URLs.
Since phishing techniques constantly evolving, periodically
updated datasets are critical [ 48]. More studies are needed to
create different web phishing datasets, enabling researchers
to assess their models’ performance more efﬁciently. To
address these challenges, this study aims to create the pri-mary dataset based on the samples collected from trusted
sources, namely Kaggle [ 24], Alexa [ 22], and PhishStorm
[26]. Figure 5presents the details of the data collection mod-
ule.

5.4 Future studies
There are several future study directions. First, futureresearch should be extended to explore phishing detection
on IoT devices and mobile platforms using different artiﬁ-
cial intelligence techniques since attackers are focusing onthese areas. Second, this study presents the summarized liter-
ature and recent advancements in phishing attacks, which can
be utilized to develop additional informational materials andadvanced training programs for users to create awareness.
Third, future studies should emphasize developing a hybrid
phishing detection model and include the beneﬁts of existingphishing detection methods. Fourth, future research shouldexplore the applications of large language models (LLMs) in
recognizing phishing attacks using the generated data.
6 Conclusion
Phishing is a cyber-attack that targets Internet users through
social engineering and deception. Despite the availability
of existing detection methods, phishing attacks continue to
increase rapidly, causing millions of dollars in user lossesand highlighting the need for more advanced detection tech-
niques. To address this challenge, a web phishing dataset
has been systematically created to explore additional unseenfeatures and extend the existing studies. The study proposed
a deep-leaning-based EGSO-CNN model with optimization
techniques to enhance the performance with low false posi-tive and error rates in phishing detection. The proposed modelhas been evaluated using three experimentations, yielded
an accuracy of 99.44%, and is further validated with a
different dataset. The model demonstrates strong potentialfor real-world applications, and its performance could be
enhanced by exploring alternative deep learning approaches
and incorporating transfer learning techniques with optimiza-tion. Ultimately, the proposed model can signiﬁcantly aidorganizations in implementing effective web phishing pre-
vention strategies, thereby enhancing customer satisfaction
and their reputation in an increasingly competitive market-place.
